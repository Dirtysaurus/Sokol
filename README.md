# Simulátor Sokolovna

3D simulátor divadelního svícení pro jeviště sokolovny v Pyšelích.

Celá aplikace je jeden soubor `index.html` (model sálu i knihovna Three.js jsou uvnitř), běží v prohlížeči bez instalace a bez internetu.

- Web: https://dirtysaurus.github.io/sokol/ (po zapnutí GitHub Pages)
- Lokálně: stáhni `index.html` a otevři dvojklikem.

Projekt (svítidla, kanály, cue) se ukládá v prohlížeči a do souboru `.sokolovna.json` přes sekci Projekt.
