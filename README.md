# Simulátor Sokolovna

3D simulátor divadelního svícení pro jeviště sokolovny v Pyšelích.

Celá aplikace je jeden soubor `index.html` (model sálu i knihovna Three.js jsou uvnitř), běží v prohlížeči bez instalace a bez internetu.

- Web: https://dirtysaurus.github.io/Sokol/
- Lokálně: stáhni `index.html` a otevři dvojklikem.

Projekt (svítidla, kanály, cue) se ukládá v prohlížeči a do souboru `.sokolovna.json` přes sekci Projekt.

## Cue list zvuku – Sen

Editovatelný cue list hudby ke Snu je v `zvuk/index.html` (jeden soubor, bez instalace).

- Web: https://dirtysaurus.github.io/Sokol/zvuk/
- Úpravy se ukládají v prohlížeči. Pro sdílení: **Uložit soubor** (`.sen-cue.json`) → poslat → druhý zvukař **Načíst soubor**. Export do CSV a tisk jsou v horní liště.
